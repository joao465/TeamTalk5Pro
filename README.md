# TeamTalk5Pro

TeamTalk5Pro é uma versão modificada do TeamTalk 5 com novos recursos voltados principalmente para áudio, praticidade e atualização do programa.

## Novos recursos

- **Equalizador do microfone principal** para ajustar o áudio diretamente no TeamTalk.
- **Microfone secundário**, permitindo escolher uma segunda entrada de áudio além do microfone principal.
- **Escuta do microfone secundário**, para ouvir e conferir a segunda entrada antes de usar.
- **EQ separado do microfone secundário**: o equalizador atua somente no microfone principal, sem alterar o áudio da entrada secundária.
- **Configurações próprias do TeamTalk5Pro**, separadas da instalação normal do TeamTalk 5.
- **Instalador próprio para Windows x64**.
- **Versão portátil**, que pode ser usada sem instalação tradicional.
- **Atualização automática**, sem precisar baixar manualmente uma nova cópia do programa a cada versão.

## Atualizações automáticas

Quando uma nova versão estiver disponível, o TeamTalk5Pro mostrará a versão instalada e a nova versão disponível, perguntando se você deseja atualizar.

Ao escolher **Sim**, o programa baixa a nova versão e inicia o instalador automaticamente.

## Sobre o projeto

TeamTalk5Pro é baseado no projeto de código aberto [TeamTalk 5](https://github.com/BearWare/TeamTalk5), desenvolvido pela BearWare.dk. Este repositório contém modificações e recursos adicionais sobre o projeto original.
